Statement, data, an empty model file for your agent to build, and an independent checker. Checker-proven feasibility counts more than the objective value.

Turn it in

The same turn-in, from whichever tool you have
FromType
Claude Code/turn-in 01
Codex$turn-in 01
A terminal, at the repository rootscripts/turn-in.sh 01

It runs the P01 checker first and stops if the checker fails. Then it commits only sessions/01-fundamentals/exercises/ to your own branch, homework/s01/<handle>, never to main. Every run adds a commit, so you can turn in again. Without push access to the course repository it pushes to your fork and prints a compare link. The repository is public, so homework branches are public too.

How we work in the room

Watch
The instructor demos. Note what the agent claims.
Predict
Commit and lock in before the reveal.
Drive
Hands on your own agent.

Sticky notes on your laptop lid tell the room how you are doing: green means done or fine, red or pink means stuck, and someone comes to you. In the lab ladder the notes carry a word too, as the ladder page explains. Pairs are mixed where possible, one Claude Code user and one Codex user. Every instruction today works in either.

Opening the pages

Every page is a plain HTML file that works offline. Double-click it, or open its file:// path in a browser. No server and no network are needed. Decks move with the arrow keys, Page Up and Page Down, or the Previous and Next buttons; on a narrow window they read as one long page.
