Attention is a soft database lookup

A query scores every key, softmax turns the scores into a probability measure over the records, and the output is the expectation of the values under that measure. A dictionary returns the one value whose key matches; attention returns a weighted average of all of them.

Toy: where does “is” look?

Everyone knows the capital of France ▸ is

The new token “is” sends a query q: what it looks for. Each earlier token offers a key ki and a value vi. The output o is the new vector for “is”.

Illustrative: the keys and values of the, capital, of and France are invented points in the plane, chosen so the lookup is easy to see. No model produced these numbers. In a real model, “is” also looks at itself.

wi = softmaxi(s · q·ki) = exp(s · q·ki) / Σj exp(s · q·kj)
o = Σi wi vi = Ew[v],   with s = 1/√d

q = (1.00, 0.50)
s = 0.71 · equivalent d ≈ 1.98

The slider sets s directly; the equivalent key dimension is d = 1/s². This toy has d = 2, so its true factor is 1/√2 ≈ 0.71. Larger s sharpens the measure towards the best-matching key; s = 0 spreads it evenly.

Try it: point q at one key and raise s until nearly all the mass sits on that key's value. That is a hard lookup. Lower s and the output slides towards the plain average of the values.

Two lines the picture leaves out

Permutation-equivariance
Without position information and without a causal mask, attention treats its inputs as a set, so permuting the tokens permutes the outputs the same way; GPT-2 breaks this on purpose with position embeddings and its causal mask.
Multi-head attention
Each head has its own learned query, key and value projections, so it computes its own measure and expectation; GPT-2 small runs 12 heads in each of its 12 layers and concatenates their outputs before a final projection.
