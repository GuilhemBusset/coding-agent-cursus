Step through it

          
Use Previous and Next, or focus the step box and press the arrow keys, Home or End.

          
    
            
  • The lane lights the phase of the loop the agent is in: gather (read, list, search, or run the tests before any change), act (change a file) or verify (run the tests, the program or a diff after a change). The page decides from the tool name and command alone, so treat it as a reading aid.
    • 
            
  • The meter shows the context sent with the latest model call and the input sent so far. Only Claude Code's stream reports usage per call; for the other runs it says so and shows the CLI's end-of-run counters.
    • 
            
  • A prediction point is a tool call where the agent switches phase. Choose, lock in, then reveal the call it really made. With a class, let everyone lock in before anyone reveals.

Where these runs come from

        
The three demos and their runbooks are in cursus/demos/agent/: the agent loop (read, pytest red, fix, pytest green, once per harness), plan first vs straight to code (three calls per rehearsal: direct, plan, build) and the context bomb (one-word answers with and without a noisy MCP server, plus the /context or /status captures). Each demo was rehearsed twice with each CLI on 2026-10-16. The CLI versions, models and token tables are in each runbook.

        
The three tasks (flipped-sense, impossible and context-bomb) were each recorded once per harness on 2026-10-16. The scenarios, isolation and evidence are in cursus/fixtures/runs/README.md. Pick one, tick Side by side, and step both harnesses through the same task.

        
Gather, act, verify is how Anthropic describes Claude Code's loop (How Claude Code works). OpenAI's Unrolling the Codex agent loop describes the same cycle of model call, tool call and result fed back, with the whole transcript sent again on every call.

        
After any new recording, rebuild the catalog and this page's copies from sessions/01-fundamentals: uv run cursus/fixtures/runs/normalize_runs.py. Both formats are described in cursus/fixtures/runs/README.md.
