## What the page is

This is the first, minimal version of the agent-loop replay widget, built to meet issue #41's "every
demo's recorded fallback plays in the widget". It was scaffolded with
`node tools/html-pages/create-page.mjs --kind lab`, and the starter's budget lab was removed. The
inline catalog is a byte copy of `../../fixtures/runs/agent-demos.json` (schema 1, 26 runs,
213 steps, 45 of them cut at 1,200 characters). It is generated by
`../../fixtures/runs/normalize_runs.py` from the raw streams in `../../demos/agent/recorded/`. The
page uses no fetch, CDN or remote font.

Behaviour:

- One native, labelled `<select>`, grouped by demo (loop, plan, bomb).
- One toolkit `[data-stepper]` per run, built before the shared `init` enhances them. Only the
  selected run's stepper is shown, and switching runs goes back to step 1.
- Each step shows a type badge, the tool name, `exit code N`, an `error` flag when set, a
  character count, and the text in a `<pre>`. A note marks truncated or empty texts.
- A shared header shows CLI and version, model and its source, effort, UTC start and end, CLI
  exit code, every usage counter as reported, and "not recorded" for per-step data.
- Bomb runs get one `<details>` with the full before and after captures. For other runs it is
  detached, so print never shows an empty disclosure.
- `#run=<id>` preselects a run. `<noscript>` gives the terminal replay commands.

The widget has no predict-and-reveal, gather/act/verify lane, meter or side-by-side mode. #47
extends this page with those, and #42 extends schema 1 with its own streams.

## Prose and source review

- Every number on the page comes from a recording: usage, times, exit codes and versions. None
  is illustrative, and the footer says so. The only dates are the 2026-10-16 recording dates.
  The page makes no "latest" claims, and the tool-search findings with their sources stay in
  `../../demos/agent/context-bomb.md`.
- The model's provenance is spelled out: "reported" means the stream named the model. "Requested"
  means it is the `-m` value, because `codex exec --json` names none.
- No CLI is preferred over the other. Both harnesses have every demo in the selector (ADR 0002).
