Toolkit reference · Session 1

Shared interaction components

Four building blocks for Session 1 widgets: a predict-and-reveal card, a probability-bar chart, a slider with a live formula readout, and a step-through controller. All numbers on this page are illustrative.

Predict, lock in, then reveal

Everyone chooses and locks in first. Reveal only becomes available after Lock in, so the class can commit before anyone sees the answer.

Predict card

The temperature drops from 1.0 to 0.2. What happens to the probability of the most likely next token?

Answer: it rises toward 100%.

Dividing every logit by a small temperature stretches the gaps between them, so softmax puts almost all of the probability on the top token. Try it with the slider below.

Probability bars with a live formula

The chart shows next-token probabilities for one prompt. The slider changes the sampling temperature, and the readout shows the formula with the current value substituted.

Step through the agent loop

Use Previous and Next, or focus the steps and press the arrow keys, Home or End.

1 · Read

The agent reads the task, the relevant files and the existing tests before touching anything.

2 · Plan

It names the change, the files it will edit and the evidence that will show the change works.

3 · Edit

It makes the smallest change that satisfies the plan, keeping unrelated code untouched.

4 · Test

It runs the tests and reports the actual results, including anything it could not verify.

Step 1 of 4

Exit ticket

The same component with two questions. Lock in needs an answer to both.

Two-question exit ticket

1. Which step should come before the agent edits any file?

Answer: read the task and plan the change.

A plan names the files and the evidence up front, so the edit stays small and the review has something to check against.

2. Raising the temperature from 1.0 to 2.0 makes sampled text…

Answer: more varied.

A higher temperature flattens the distribution, so less likely tokens get picked more often. In the chart above, “passed” drops from 58.5% to 39.3%.
