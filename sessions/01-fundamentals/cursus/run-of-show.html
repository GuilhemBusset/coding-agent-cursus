Session 1 · Instructor · Run of show

Four hours, minute by minute.

Every segment of the day with its mode, the file on the projector, the demo command, the fallback if the demo fails, and what helpers watch for. Times are from the start of the session.

Read this first

Watch
The instructor demos. Students note what the agent claims.
Predict
Everyone commits and locks in before the reveal.
Drive
Students work on their own laptops, with their own agent.

These times are a plan, not a measurement. The opening and Acts I and II follow the data-minutes on their slides; none of them has had a timed rehearsal yet. Act III follows its speaker notes, Act IV the lab ladder’s time boxes. Act V and the close are split here from their block lengths. Times with seconds come from slides planned in half minutes.

Every demo runs on the instructor’s Linux machine only; students never run demos (ADR 0010). Each command is run from the demo’s own folder, named in the row. Each live demo has a recorded fallback that needs no agent and no network. Switch to the fallback at the first sign of a login prompt, an exhausted quota or a dead network; do not debug in front of the room.

Sticky notes: the lab ladder in Act IV introduces three notes, each with its word (green DONE, yellow STUCK, pink CLAIM ≠ EVIDENCE). Helpers go to a yellow or pink note, help the student find the next step themselves, and come back to the instructor with anything two students share.

Before the room opens

  1. In sessions/01-fundamentals: uv sync --locked, so every uv run --offline fallback works with no network.
  2. Log in to both CLIs: run claude and type /login; run codex login. Send one short prompt to each.
  3. Run every fallback once, offline: uv run --offline effort.py replay in cursus/demos/effort, uv run --offline strawberry.py --replay and uv run --offline sampling.py --replay in cursus/demos/model, uv run agent_demo.py replay loop --via claude in cursus/demos/agent.
  4. Reset the demos: the reset line in the cold-open runbook, the effort runbook and the model runbooks; uv run agent_demo.py reset loop and uv run agent_demo.py reset bomb in cursus/demos/agent.
  5. Open browser tabs in order: the session hub, the six decks, the nine labs and the lab ladder. Keep a second terminal open in cursus/demos/agent with the replay commands typed.
  6. Pick the L2 variant from the P00 instructor notes. Do not write it on the board until 2:55.
  7. Board: leave room for the discipline sentence and for p(xt | x1, …, xt−1). Sticky notes (green, yellow, pink) and a pen on every table.
  8. Helpers: collect the setup-check summaries students pasted before the session, and know who printed a FAIL.
