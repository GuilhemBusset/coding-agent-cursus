The cursus

Each session hands an agent a bigger piece of your research.

Speaker notes

While it works, here is what this technology opens for a scientist: one new thing per session.

Today, Fundamentals: what a model and an agent really are, then you drive one, up to a word problem turned into a model a checker certifies. That is what is running behind me.

Research agents: a team of agents drafts a literature review, and a write-up from your own experiment logs, with every citation traceable.

Remote agents: the same agent runs headless in a cloud sandbox; you file an issue and get back a pull request with its evidence, laptop closed.

Deploying: every merge re-solves the canonical instance on a pinned open solver and regenerates the study.

The Arena: a cohort tournament on a rolling-horizon problem; you improve your policy by filing issues to agents, and it is ranked on instances nobody has seen.

One problem family runs through all five. Tonight’s take-home is an electric-truck middle-mile network, the world I work in.

Speaker notes

Not only software: research mathematics, across analysis, combinatorics, geometry and number theory. AlphaEvolve is a Google DeepMind coding agent, and Terence Tao is among the authors of this paper.

The mechanism: a model proposes programs, an automatic evaluator scores them, and the best programs seed the next round, at a scale no person could try by hand.

That loop, a generator plus something that scores it, is a pattern you can build for your own problems.

Cold open · Back to the agent

It ran while we talked. Lock in before we look.

The workshop’s best weekly plan makes:

A mix: 20 tables and 20 chairs, profit 1400 euros. Primal and dual feasible, zero gap: optimal.

Speaker notes
  1. Glance at the terminal: did the run finish? Claude Code: the last line is the JSON result event with "subtype":"success". Codex: after the file diff, a tokens used line and its count, then the final answer printed once more. Still running, an error, or neither: use the fallback below.
  2. Hands up for each choice; press Lock in with the majority. Do not reveal yet.
  3. Terminal: cat work/model.py. Compare it with problem.md: two variables, the three hour constraints and their coefficients, maximise profit, non-negative quantities. The answer is nowhere in the prompt.
  4. uv run python work/model.py: the same command the agent ran, about a second, seven clean lines.
  5. Check the certificate by hand with the room. Primal feasible: assembly 20 + 20 = 40 ≤ 40, carpentry 40 + 20 = 60 ≤ 60, finishing 20 + 60 = 80 ≤ 90 (10 h slack). Dual feasible: the duals 20, 10, 0 are non-negative; tables 20 + 2×10 = 40 ≥ 40, chairs 20 + 10 = 30 ≥ 30. Objectives: primal 40×20 + 30×20 = 1400, dual 40×20 + 60×10 + 90×0 = 1400, so the gap is zero (floating-point residuals near zero are fine). No plan can beat it, and we did not have to trust the agent or the solver.
  6. Back to the slide, press Reveal.
  7. Read the duals as prices: an assembly hour is worth 20 euros, a carpentry hour 10, a finishing hour nothing, because finishing has slack.
  8. If the run printed a wrong sign or a non-zero gap, show it: nothing is proven, and the check is what caught it.

Fallback (no network, quota, login prompt, stalled or failed run), in place of steps 3 and 4: scroll recorded/claude-run2.txt, then uv run --offline python recorded/claude_run2_model.py. Codex room: recorded/codex-run2.txt, then uv run --offline python recorded/codex_run2_model.py. Both print the same certificate in seven lines; continue from step 5.

The one discipline

The more you can check, the more you can hand over.

Never raise an agent’s autonomy past your ability to verify the solution, not just the code.

Speaker notes

Do: write the sentence on the board.

What made the cold open trustworthy was the certificate, not the agent’s word.

Read the sentence as a licence, not a brake: each session hands agents more, and each adds the checks that make that safe. Autonomy rises as fast as verification does. It goes on the board today and stays the rule for the whole cursus.
