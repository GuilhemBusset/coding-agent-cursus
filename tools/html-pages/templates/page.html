A small, testable contract makes an agent’s work easier to review. Start with behavior, constrain the change, and name the evidence you expect.

Specify the observable result

“Fix validation” leaves the agent to invent requirements. A useful task says what input changes, what output should follow, and which existing behavior must survive.

Exercise · Write a bounded task

Implement parse_count(text): trim surrounding whitespace, accept ASCII digits representing 1–99, and raise ValueError otherwise. Change only the function and its tests; add no dependencies.

Turn the contract into examples

Why constrain digits explicitly?

Python’s str.isdigit() accepts some non-ASCII characters. The contract deliberately narrows the accepted alphabet so the implementation and reviewer agree on what “digits” means.

Compare against an exact implementation

Try the exercise first. Then inspect how each condition below corresponds to one part of the contract.

def parse_count(text: str) -> int:
    value = text.strip()
    if not value or any(c not in "0123456789" for c in value):
        raise ValueError("Use ASCII digits for a count from 1 to 99")
    significant = value.lstrip("0")
    if not significant or len(significant) > 2:
        raise ValueError("Count must be between 1 and 99")
    return int(significant)
